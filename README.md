# RSVP-CASE-STUDY

“I worked on an RSVP Movies case study where I analyzed movie, genre, ratings, and financial data using SQL.
I wrote complex queries using joins, CTEs, window functions, subqueries, and aggregations to extract business insights such as revenue trends, top-performing genres, director performance, rating distributions, and year-wise growth.
The goal was to help stakeholders make data-driven decisions on content investment and market strategy.”
